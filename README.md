# 邮箱通知

邮箱通知是 SkyTide 的单邮箱插件。它定期检查新邮件，并将发件人、主题、时间和正文预览发送到你选定的机器人会话。

版本 `1.0.0` · 作者 `yutan123`

## 安装

1. 在 SkyTide 打开「侧边栏 → 插件 → 导入」。
2. 选择 `skytide_mail_notify-1.0.0.zip`，无需解压。
3. 在插件列表打开「邮箱通知 → 设置」。

## 配置

1. 在邮箱服务商的账户设置中启用 IMAP，获取应用专用密码或授权码。
2. 在插件设置的「邮箱账户」中开启「启用设置中的邮箱账户」，填写邮箱地址、IMAP 服务器、端口和授权码。可填写备注名，供状态页和聊天命令使用。
3. 在「通知与命令」中选择通知机器人，并在 SkyTide 中授权该机器人使用插件。需要在聊天中执行命令时，再选择获准执行命令的机器人。
4. 保存设置并启用插件。在设置中点击「测试主邮箱 IMAP 连接」。

| 协议 | 直接 TLS 常用端口 | STARTTLS 常用端口 |
| --- | --- | --- |
| IMAP 收信 | 993 | 143 |
| SMTP 发信 | 465 | 587 |

以邮箱服务商提供的服务器地址和端口为准。使用 STARTTLS 时，关闭对应的「使用直接 TLS」选项。插件使用授权码或密码登录。仅提供 OAuth 登录的邮箱无法连接。

需要通过聊天命令发信时，开启「配置 SMTP 发信」，填写 SMTP 服务器和端口。若 SMTP 与 IMAP 使用同一个授权码，可将 SMTP 授权码留空。

## 使用

- 在插件页选择「打开界面」，查看当前邮箱、通知机器人和最近检查结果。
- 首次成功检查时，插件记录已有邮件的位置，之后只通知新邮件。单轮最多处理最新 10 封新增邮件。
- 在设置中调整检查间隔、显示时区和黑白名单。多条规则用英文分号或换行分隔，黑名单优先。启用白名单后，只有匹配的邮件才会通知。

### AI 摘要

在插件设置中开启「启用 AI 摘要」，选择聊天模型提供商。插件将解码后的邮件正文和邮件信息提交给所选提供商的默认模型，生成自然语言摘要，再投递到通知机器人会话。邮件正文最多提交 16,000 个字符。摘要关闭或生成失败时，继续发送固定格式通知。

### 让机器人发邮件

开启「配置 SMTP 发信」，并在「允许使用邮箱命令的机器人」中选中对应机器人。在会话里提供收件人邮箱、主题和正文，明确要求发送。机器人可通过 `send_email` 向单个收件人发送纯文本邮件。

### 聊天命令

以下命令只能在已获授权的机器人会话中使用。示例中的 `主邮箱` 可替换为设置中的邮箱备注名或完整邮箱地址。

| 命令 | 用途 |
| --- | --- |
| `/mail_check` | 立即检查新邮件 |
| `/mail_status` | 查看邮箱、通知目标和检查状态 |
| `/mail_query 主邮箱 2026-03-01` | 查询指定日期以来最新 20 封邮件的发件人、主题和时间 |
| `/mail_reply 主邮箱 receiver@example.com 主题\|正文` | 通过已配置的 SMTP 向一个收件人发信 |
| `/mail_bind` | 设置未选择通知机器人时，绑定当前机器人作为通知目标 |

## 常见问题

### IMAP 连接失败

确认邮箱已开启 IMAP，服务器和端口填写正确，TLS 模式与端口匹配，并使用服务商签发的有效授权码或应用专用密码。

### 连接成功但没有收到通知

确认插件已启用、通知机器人已获授权，并在首次成功检查后发送一封新邮件。若启用了黑白名单，确认测试邮件符合过滤规则。


从 TideBot 迁移时，旧插件设置不会随 ZIP 导入，请在 SkyTide 重新配置邮箱和机器人授权。
